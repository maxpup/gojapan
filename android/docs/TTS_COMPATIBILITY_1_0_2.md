# 1.0.2 日语引擎兼容修复

## 用户截图确认的现象

日语包安装页面显示已有语音数据，但应用提示“缺少可离线使用的日语语音”并禁用播放。旧代码把语言不可用、voice 枚举失败、只有联网 voice 等不同情况合并为同一错误；静态条件足以误拒绝有效语音。截图不能证明应用与安装页面使用了同一 TTS 引擎，也不能确定该设备的 API 返回值。

## 修复

- 先请求 ja-JP，再按需请求 ja；优先离线语音，但允许已确认的联网日语 voice，并明确提示需要网络。
- 支持语言选择成功、当前语言为 `ja` 或 `jpn`，但未实现 voice 枚举/当前 voice 的旧式引擎。
- 当前 voice 明确为中文/英文、选择失败后未切到日语、语音尚未安装时，仍不允许播放。
- 应用内显示当前引擎，并允许选择安装了日语包的其他引擎；选择持久保存。
- 安装按钮限定到应用当前引擎的安装页面。返回应用时重新初始化，不自动播放。
- 区分缺少数据、不支持日语、无法确认日语，以及网络、输出、下载未完成等播放错误。
- 全局栏加入版本入口，显示应用版本、构建类型和通过 PackageManager 读取的实际安装证书 SHA-256，可复制用于排查签名冲突。
